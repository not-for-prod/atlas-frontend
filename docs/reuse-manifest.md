The two Polymarket engineering skills' `.skills` and `.codex/skills` copies were compared and were identical at extraction. The new project maintains only `.agents/skills`. The generic design-search skill is not included; Atlas's visual baseline is already defined.

Resolved discrepancies: individual hooks instead of `lib/hooks.ts`; entities own generated business imports; inline type imports match lint; preview inputs are clearly presentation-only; accessibility rules are retained. Typography/tokens follow current AtlasPay, including card-only gradients/shadows. Muted text is darkened for readability. No unconfirmed card network or mobile-wallet logos are copied.

Playwright is the one additional development tool introduced for responsive, keyboard and production-isolation verification. It is pinned in the lockfile; tests use a locally installed Chrome via `PLAYWRIGHT_CHANNEL=chrome`, or bundled Chromium after `bun x playwright install chromium`.

Cabinet migration: AtlasPay `renderHome`, `renderTopup`, `renderHistory`, `renderIssue`, `renderCard`, `renderSupport` and `renderProfile` informed `src/views/Cabinet`, `src/widgets/CabinetLayout` and the reusable `DemoAction` feature. Existing React dashboard components are reused. Direct DOM routing and backend calls were replaced by Next section routes and explicitly local demo interactions; no old API contracts or financial success paths were copied.
